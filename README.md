# Parchment

Parchment is a Kotlin Android system launcher with a quiet, e-ink inspired interface.

## Included in this starter

- Monochrome paper-toned home screen with greeting, date, app search, and grayscale app shortcuts.
- Searchable All apps screen with a simple alphabetical, text-only list. Tapping an app opens it.
- Android Home intent so Parchment can be selected as the default launcher.

The EPUB reader is intentionally not included yet.

## Open in Android Studio

Open this folder in Android Studio and allow Gradle sync. The project uses Android Gradle Plugin 9.5.1 with built-in Kotlin support, Gradle 9.6 or newer, Android SDK 36, and JDK 17. If prompted, install Android SDK Platform 36 and Build Tools 36.0.0. After installing the app, choose Parchment as the default Home app in Android Settings.
